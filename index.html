            Buddy

            Your active buddy stays on the desk and can react, nap, walk, and be petted. Behavior rules cannot hide it. Roaming still respects locked-screen and full-screen safety.

            Modules

            Modules start off on a new install. Enabling one asks first; you can switch it off whenever you like.

            Behavior Lab

            Privacy and Permissions

            Modules and buddy sensors are off on a new install. Each asks before it is enabled. Data stays on this device.

            Hotkeys

            Shortcuts available in this version.

            • Ctrl + Shift + SpaceShow or hide Desk Drawer
            • 1–6Open enabled tool drawers
            • M, S, BModules, Settings, Behavior Lab
            • Ctrl + KOpen the command palette

            The global shortcut can be unavailable if another app already uses it; Desk Drawer shows a warning in that case.

            Data

            Settings, notes, links, and buddy data are stored locally. Desk Drawer does not sync them.

            Data deletion is kept in each tool so a reset cannot remove your saved work by surprise.

            Advanced

            Advanced options

            WebView DevTools are available only in development builds, not release builds.

            Developer mode

            These tools are local only. Event details are reduced to coarse metadata; clipboard contents and file paths are not recorded.

            Theme inspector

            Resolved CSS tokens, WCAG contrast checks, and synchronous theme-apply time. Timing excludes image loading and Windows material effects.
