# Onboarding tutorial and in-app copy

## First-run guide (interactive, skippable, one time)
1. **Welcome to Desk Drawer.** Your study space starts empty. This quick tour points out the real controls; they remain usable while the guide is open.
2. **Create your first course** (spotlight: Add course), or **Choose a course** (spotlight: course dock) when courses already exist. Courses contain only resources and notes the user adds.
3. **Choose how to focus** (spotlight: timer controls). The Stopwatch starts at 0:00 and counts up; countdown lengths are optional.
4. **Start your study session** (spotlight: Start). Start opens the selected course resources and begins tracking the session.
5. **Keep your study tools close** (spotlight: Resources), then **Make it yours** (spotlight: Settings).

Rules: shown once on first launch; the spotlighted controls remain clickable; Skip or Finish marks the guide done; there is no reopen button.

## Empty states
- **No courses:** “Your study desk is empty. Create a course to start building your study space.” Button: Create your first course.
- **No sessions:** “No sessions yet. Start one and it will show up here.”
- **Course with no folder or links:** “Nothing to open yet. Add a folder, files, or links in Edit, or just start the timer.”

## Buddy lines
- idle: 10 short encouragements rotate in a shuffled, non-repeating order while the Desk is open.
- start: “Opened {folder} and {n} links. Focus.” / “Timer’s running. I’ll be here.”
- pause: “Paused.” / “Take a breath.”
- resume: “Back to it.”
- done: “Nice work: {mins} min on {course}.”
- ended early: “Stopped early. {mins} min logged.”
- nudge: “It’s been {days} days since {course}.” (max one nudge per launch)

## Error messages (say what happened and what to do)
- Folder missing: “Couldn’t find {path}. Check the folder in Edit. Your timer still started.”
- Link invalid: “{text} isn’t a web link. Links must start with http:// or https://.”
- App not found: “Couldn’t open {name}. Check its path in Edit.”
- Save failed: “Couldn’t save your changes. Your data is safe on disk as of the last save. Try again.”
- Download move failed: “Couldn’t move {file}. It’s still in Downloads.”

## Help text
- Length chips: “Pick how long to focus.”
- Custom timer: “Choose a whole number of minutes from 1 to 180.”
- Halo: “The ring shows time remaining for countdowns and fades over the selected focus length for the stopwatch.”
- File references: “Files stay where they are. Desk Drawer opens them with your device’s registered app.”
- “N days” tag: “You haven’t studied this course in N days.”
- Keyboard: Space start or pause (when focus is on the stage), Esc closes the sheet or skips the first-run tour.
